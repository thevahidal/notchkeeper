Install

Up and running in a minute.

brew trust --cask thevahidal/tap/notchkeeper && brew install --cask thevahidal/tap/notchkeeper

Homebrew asks you to trust casks from third-party taps before it loads them; that's the first command. Uninstall with brew uninstall --zap --cask notchkeeper, which also disconnects Notchkeeper from Claude Code.

Download Notchkeeper.dmg

Open it and drag Notchkeeper to Applications. All releases are on GitHub.

git clone https://github.com/thevahidal/notchkeeper.git && cd notchkeeper
./build.sh
open .build/Notchkeeper.app

Needs the Xcode Command Line Tools (xcode-select --install).

First open: macOS asks you to allow Notchkeeper once. Open System Settings → Privacy & Security and click Open Anyway. Then Notchkeeper asks, in the notch, before it connects to Claude Code.
