Install

Up and running in a minute.

brew trust --cask thevahidal/tap/ping && brew install --cask thevahidal/tap/ping

Homebrew asks you to trust casks from third-party taps before it loads them; that's the first command. Uninstall with brew uninstall --zap --cask ping, which also disconnects Ping from Claude Code.

Download Ping.dmg

Open it and drag Ping to Applications. All releases are on GitHub.

git clone https://github.com/thevahidal/ping.git && cd ping
./build.sh
open .build/Ping.app

Needs the Xcode Command Line Tools (xcode-select --install).

First open: macOS asks you to allow Ping once. Open System Settings → Privacy & Security and click Open Anyway. Then Ping asks, in the notch, before it connects to Claude Code.
